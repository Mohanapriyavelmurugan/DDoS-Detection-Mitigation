How monitoring works

  1. Detector captures or simulates network flows.
  2. Three-layer fusion scores each flow and assigns a mitigation tier.
  3. Events stream here over WebSocket for live view and durable history.

  2. From the attacker container, run a controlled attack against the detector.
  3. New attacks appear live; previous attacks from this session stay in History.
